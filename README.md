# Plenna v1

Central operacional para **Sarah Teixeira — Social Media & Storymaker**.

## O que já está pronto

- Dashboard diário responsivo
- Agenda mensal e compromissos
- Gestão visual de clientes
- Kanban de conteúdos
- Briefings e andamento do onboarding
- Reuniões e roteiro de onboarding
- Módulo Storymaker para coberturas
- Biblioteca de arquivos
- Tela de configurações e integrações

Esta primeira versão usa dados demonstrativos para validar a experiência antes da conexão com banco de dados.

## Executar localmente

Requisitos: Node.js 20.9 ou superior.

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Publicar na Vercel

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para o repositório.
3. Na Vercel, clique em **Add New > Project**.
4. Importe o repositório.
5. Mantenha o preset **Next.js** e clique em **Deploy**.
